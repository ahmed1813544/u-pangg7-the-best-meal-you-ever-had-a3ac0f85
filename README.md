Entry for the [make.fun bounty "The Best Meal You Ever Had"](https://make.fun/bounty/u-pangg7-the-best-meal-you-ever-had-a3ac0f85).

`main.py` (Python 3.13, stdlib only, no network) writes a single sentence — at
most 200 characters — about the best meal the writer ever had, to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program
is deterministic: every run writes the same bytes.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
